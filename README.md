# 応用一般均衡（CGE）モデル

コブ＝ダグラス型効用関数・生産関数を用いた2財2要素の静学的CGEモデルです。  
パン（BRD）と牛乳（MLK）を生産する経済を想定し、技術変化が均衡価格・消費量・厚生に与える影響を分析します。

## モデルの概要

| 要素 | 内容 |
|------|------|
| 財 | パン（BRD）、牛乳（MLK） |
| 生産要素 | 資本（CAP）、労働（LAB） |
| 家計効用 | コブ＝ダグラス型（$\alpha_{BRD}=0.3,\ \alpha_{MLK}=0.7$） |
| 生産技術 | コブ＝ダグラス型（各財で資本・労働のシェアを設定） |
| 要素賦存量 | 資本 25、労働 25 |
| ニュメレール | 労働価格 $p_{LAB}^f = 1$ |

### ベースライン要素シェア

| | 資本シェア | 労働シェア |
|-|-----------|-----------|
| BRD | 1/3 | 2/3 |
| MLK | 4/7 | 3/7 |

## 分析内容

BRDの生産技術が変化し（資本・労働シェアが各1/2に変更）、新均衡における以下の変化を計算します。

- 均衡要素価格・財価格
- 消費量の変化（問2(7)）
- 等価変分 EV（問2(8)）

## 実行結果

```
--- 新均衡 ---
p_CAP_f' = 1.2222
p_BRD    = 1.1700
p_MLK    = 1.1215
I        = 55.5556
X_BRD    = 14.2455
X_MLK    = 34.6757

--- 問2(7) 消費量の変化 ---
ΔX_BRD = 14.2455 - 15.0000 = -0.7545
ΔX_MLK = 34.6757 - 35.0000 = -0.3243

--- 問2(8) 等価変分 EV ---
U_base = 27.1441
U_new  = 26.5535
EV     = -1.0879
→ EV < 0：技術変化により家計の厚生は悪化した
```
